闪亮星骑士 简体中文汉化增强包
基于 TSKHook · 安装 + API 配置(一图流)
仅需 4 步 + 可选 1 处配置
0 · 前提(必看)
!
游戏不带任何汉化插件,先去上游装 TSKHook 基础版 (自带 BepInEx6 注入 + 繁体插件 + 字库),确认繁体生效后再装本包。
github.com/TSKModding/TSKHook
1 · 安装(四步)
1
下载完整包(约 183MB)并解压
2
找到文件夹「1-汉化插件」
3
把里面的 BepInEx 整体复制到游戏目录
C:\Users\你的用户名\Twinkle_StarKnightsX\
提示:覆盖时跳过 config.json(里面有你的设置)
4
启动游戏 → 简体生效
改完词典按 F10 重载,不用重启
2 · API 自动补翻(可选)
+
记事本打开 BepInEx\plugins\config.json,把 translationApi 改成:
{
  "enabled": true,
  "url": "https://api.deepseek.com/v1/chat/completions",
  "key": "你自己的密钥",
  "model": "deepseek-chat"
}
支持 DeepSeek / 通义 / Kimi 等 OpenAI 兼容接口 · 密钥别发给别人 · 不想要可跳过
3 · 快捷键
F5 暂停 · F6 恢复 · F7 减速 · F8 加速
F10 重载词典 · F11 开关汉化 · F12 截图 · Ctrl 跳过剧情
⚠ 使用修改插件违反游戏与 DMM 用户协议,可能封号,请用小号测试,风险自负
